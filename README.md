# YMControls 3.0.24 — Vencord/Equicord userplugin

Один и тот же каталог `ymControls.desktop` работает как userplugin в актуальных исходниках Vencord и Equicord. Для работы необходим обновлённый аддон **YMControls 3.0.x** в PulseSync.


## Изменения в 3.0.24

- Исправлена загрузка обложек в Linux: основной процесс теперь использует `electron.net.fetch`, то есть сетевой стек Chromium/Electron с его прокси и сертификатами.
- Сырые URL Яндекс Музыки с размерными шаблонами `%%`, `{size}` и `%s` автоматически преобразуются в рабочий размер `400x400`.
- Если native IPC временно недоступен, плагин пробует прямой HTTPS-адрес вместо полного скрытия обложки.

## Изменения в 3.0.23

- Убрано скругление верхних углов компактного плеера, из-за которого по краям был виден фон панели Discord.
- Контейнер `#vc-pulsesync-mount` теперь принудительно занимает всю ширину без внешних отступов и обрезает содержимое по своим границам.
- Фон компактного плеера заполняет всю верхнюю область слева направо в Vencord и Equicord.


## Изменения в 3.0.22

- Исправлен запуск в Equicord: YMControls больше не стартует на стадии `Init`, когда webpack-модули Flux ещё недоступны.
- Плагин запускается на стандартной стадии `WebpackReady`, поэтому `PulseSyncStore`, плеер и кнопка **YM** создаются только после инициализации webpack.
- Зависимость `ServerListAPI` сохранена, поэтому кнопка продолжает работать и в Vencord, и в Equicord.
- Webpack-патч нативной кнопки остаётся зарегистрированным до запуска плагина и не требует `startAt: Init`.


## Изменения в 3.0.19

- Добавлена явная зависимость `ServerListAPI`, поэтому кнопка **YM** отображается не только в Equicord, но и в чистом Vencord.
- Плагин запускается на стадии `Init`, чтобы API списка серверов активировался до построения интерфейса Discord.
- Кнопка по-прежнему добавляется через `@api/ServerList` и не зависит от хешированных CSS-классов Discord.

## Установка

Скопируйте каталог `ymControls.desktop` в:

```text
<Vencord или Equicord>/src/userplugins/ymControls.desktop
```

Файлы `index.tsx` и `native.ts` должны находиться непосредственно в этом каталоге. Затем выполните из корня Vencord или Equicord:

```bash
pnpm build
pnpm inject
```

Полностью закройте Discord, включая значок в системном трее, запустите его снова и включите **YMControls**.

Локальный мост:

```text
WebSocket: ws://127.0.0.1:24891/ymcontrols
Health:    http://127.0.0.1:24891/health
Covers:    http://127.0.0.1:24891/cover?url=...
```

Проверка из Discord DevTools:

```js
await VencordNative.pluginHelpers.YMControls?.getStatus?.()
```

## Темы

В настройках **Player theme** доступны:

- `Custom color` — используется значение **Custom player background**;
- `Discord theme` — используется фон текущей темы Discord;
- `Cover color` — используется доминирующий цвет текущей обложки.

Цвет текста, иконок, кнопок и слайдеров выбирается автоматически:

- для `Custom color` — по яркости выбранного HEX-фона;
- для `Discord theme` — по текущей светлой или тёмной теме Discord;
- для `Cover color` — по яркости доминирующего цвета обложки.

Отдельного переключателя светлой темы больше нет.

## Обложки в Vencord и Equicord

Некоторые сборки Discord блокируют CDN Яндекс Музыки политикой CSP. Поэтому обложки с `avatars.yandex.net` и `avatars.mds.yandex.net` загружаются главным процессом через ограниченный loopback-прокси `/cover`.

Прокси:

- принимает только HTTPS;
- разрешает только два домена обложек Яндекс Музыки;
- проверяет каждый redirect;
- принимает только `image/*`;
- ограничивает размер ответа 8 МБ;
- не открывает произвольный сетевой прокси.

## Ограничения очереди и качества

Основное управление плеером выполняется через `window.pulsesyncApi`. Очередь, reorder/remove и качество могут находиться во внутренних объектах `window.sonataState`, структура которых меняется между версиями PulseSync и Яндекс Музыки.

YMControls ищет доступные структуры и методы во время выполнения. Поэтому:

- просмотр очереди работает только когда PulseSync предоставляет распознаваемый массив сущностей;
- технические команды изменения очереди остаются в протоколе, но в интерфейсе 3.0.1 отдельные кнопки перемещения и удаления скрыты;
- воспроизведение элемента имеет дополнительный DOM fallback через панель очереди;
- после обновления PulseSync или Яндекс Музыки селекторы и внутренние поля могут потребовать адаптации.


## Font

The player uses `JetBrainsMono Nerd Font` when it is installed in Windows. It falls back to `JetBrains Mono` and then to the system monospace font.
