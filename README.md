# YMusicSync - A plugin for [Equicord](https://equicord.org/) 

## Features

- **Track control panel above the account panel**
- **Synchronization via the native Ynison protocol**
- **Control of Yandex Station speakers**
- **Discord Rich Presence**

## Configuration

1. Open the plugin settings and paste your **Yandex Music OAuth token** - it's used to connect to Ynison
2. Toggle the player panel, settings button, volume slider, and auto-hide-after-pause to your liking
3. In the **Discord RPC** section, configure the activity display: name, track link button
